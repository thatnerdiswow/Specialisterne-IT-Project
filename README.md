# Specialisterne-IT-Project
This repository contains hands-on labs demonstrating troubleshooting and network security concepts.
-This IT project will focus on identifying and solving a real technology problem.
-The goal is to show how I investigated the problem, troubleshoot the issue, and explain my solution.

## Projects
- Home Network Security Audit
  Unsecured home networks can expose sensitive data and connected devices to unauthorized access, malware, or cyberattacks. Weak configurations (e.g., default passwords or outdated encryption) increase the risk of data breaches and network compromise.
- DNS Troubleshooting Lab
DNS issues prevent domain names from resolving to IP addresses, making websites inaccessible despite an active internet connection. This disrupts normal network usage and can indicate misconfiguration or potential network-related faults.
